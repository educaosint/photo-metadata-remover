# Cómo contribuir

Gracias por ayudar a mejorar LimpiaFoto.

1. Abre una incidencia explicando el problema o mejora.
2. Crea una rama específica para el cambio.
3. No agregues cargas de imágenes al servidor, seguimiento personal ni cookies.
4. Verifica que JPG, PNG, WebP y HEIC sigan procesándose localmente.
5. Conserva los créditos de `NOTICE`.
6. Envía un pull request con una explicación breve y pruebas realizadas.

Al contribuir aceptas que tu aporte se publique bajo la licencia MIT del proyecto.
